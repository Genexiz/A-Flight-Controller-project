# MiniDrone FC — บอร์ด Flight Controller โดรนจิ๋ว (ESP32-S3 + มอเตอร์ brushed)

บอร์ดนี้เป็น **ทั้งวงจรควบคุมการบินและโครงโดรน** ในชิ้นเดียว (แบบ ESP-Drone)
รูปตัว X ระยะมอเตอร์ทแยง 90 มม. ตัวบอร์ดกลาง 36 × 47 มม. PCB 2 ชั้น
ใช้แบต LiPo 1 เซลล์ (3.7V) และมอเตอร์แปรงถ่าน 716/720
สั่งงานผ่าน WiFi จากมือถือได้ เพราะ ESP32-S3 มี WiFi/BLE ในตัว

## สถานะ

- Schematic: ERC ผ่าน 0 error
- PCB: เดินลายครบทุกเส้น, DRC ผ่าน (0 violations, 0 unconnected, schematic ตรงกับ PCB)
- ยังไม่ได้สร้างไฟล์ Gerber/BOM — ทำเองได้ตามหัวข้อ "สั่งทำ PCB" ด้านล่าง

## หน้าตาบอร์ด (มองจากด้านบน, เสาอากาศชี้ไปข้างหน้า)

```
   M4 (CW)  \        [เสาอากาศ]        /  M1 (CW)
              \   ┌──────────────┐   /
                \ │  ESP32-S3    │ /
                  │              │
       USB-C ──►  │  [IMU] J3    │
         (ซ้าย)   │ ไฟ/LDO แถวหลัง│
                / │ SW1  BATT SW2│ \
              /   └──────────────┘   \
   M3 (CCW) /        ▲ ขั้วแบต         \  M2 (CCW)
```

- **USB-C อยู่ด้านซ้าย** ของบอร์ด, **ขั้วแบต (J1) อยู่กลางท้าย**, ปุ่ม RESET (SW1) ท้ายซ้าย, BOOT (SW2) ท้ายขวา
- ชิ้นส่วนทุกตัวอยู่ด้านบน ด้านล่างเป็นแผ่น GND เต็มแผ่น (ใช้แปะแบตได้)
- ทองแดงไฟมอเตอร์ (VBAT และสายมอเตอร์) กว้าง 0.8 มม. วิ่งเลียบขอบบอร์ด

## วงจรแต่ละส่วน ทำอะไร

1. **ไฟเลี้ยง (POWER)**
   - แบตต่อที่ขั้ว JST-PH 2.0 (J1) → เป็นไฟ `VBAT` 3.0–4.2V
   - `VBAT` ไปเลี้ยงมอเตอร์ตรงๆ (กระแสสูง จึงใช้ลายทองแดงกว้าง 0.8 มม.)
   - Q5 (P-MOSFET AO3401A) + D1 (ไดโอด B5819W) = **วงจรเลือกแหล่งไฟ**: เสียบ USB เมื่อไหร่ บอร์ดใช้ไฟ USB และตัดแบตออก (กันไฟ USB ไหลย้อนเข้าแบต)
   - U2 (AP2112K-3.3) แปลงเป็น 3.3V ให้ ESP32 และ IMU
   - R15/R16 แบ่งแรงดันแบตครึ่งหนึ่งเข้า ADC (IO9) เพื่อวัดแบตเหลือ
   - **มอเตอร์จะไม่หมุนถ้าเสียบแค่ USB** (ต้องมีแบต) — ปลอดภัยตอนโปรแกรม

2. **สมอง (MCU)** — โมดูล ESP32-S3-WROOM-1 (U1)
   - เสาอากาศยื่นออกหน้าบอร์ด ห้ามมีทองแดงใต้เสาอากาศ (มีพื้นที่ keep-out ไว้แล้ว)
   - ปุ่ม RESET (SW1) และ BOOT (SW2), LED แดง/เขียว, ขา DEBUG (J3)

3. **USB-C (J2)** — ต่อตรงเข้า USB ของ ESP32-S3 (IO19/IO20) ใช้แฟลชโปรแกรมและดู Serial ได้เลย ไม่ต้องมีชิปแปลง USB
   R3/R4 (5.1k) ทำให้ที่ชาร์จ/คอมยอมจ่ายไฟ 5V

4. **IMU (U3, MPU-6050)** — ไจโร + ความเร่ง วางตรงกลางบอร์ด ต่อแบบ I2C (แอดเดรส 0x68)

5. **ขับมอเตอร์ ×4** — ต่อแขนมี MOSFET AO3400A (Q1–Q4) เปิด-ปิดมอเตอร์ด้วยสัญญาณ PWM
   ไดโอด D2–D5 กันแรงดันกระชากตอนมอเตอร์ดับ ตัวต้านทาน 10k ทำให้มอเตอร์ไม่หมุนเองตอนเปิดเครื่อง

## ตารางขา ESP32-S3 (ใช้ตั้งค่าในเฟิร์มแวร์)

| หน้าที่ | GPIO |
|---|---|
| มอเตอร์ M1 (หน้า-ขวา, หมุน CW) | IO1 |
| มอเตอร์ M2 (หลัง-ขวา, CCW) | IO21 |
| มอเตอร์ M3 (หลัง-ซ้าย, CCW) | IO18 |
| มอเตอร์ M4 (หน้า-ซ้าย, CW) | IO4 |
| I2C SDA / SCL (MPU-6050) | IO11 / IO12 |
| IMU INT | IO14 |
| วัดแบต (ADC, ค่าที่อ่าน × 2 = แรงดันแบต) | IO9 |
| LED แดง / เขียว | IO2 / IO40 |
| ปุ่ม BOOT | IO0 |
| USB D- / D+ | IO19 / IO20 |
| UART TX / RX (ขา DEBUG) | TXD0 / RXD0 |

ขา DEBUG (J3, ระยะ 1.27 มม.): 1=3V3, 2=GND, 3=TX, 4=RX, 5=SDA, 6=SCL

## สั่งทำ PCB

1. สร้างไฟล์ Gerber: รัน `scripts/export_fab.sh` (ได้ `fab/` + `docs/MiniDrone_FC_gerbers.zip`)
   หรือใน KiCad PCB Editor → File → Fabrication Outputs → Gerbers (.gbr) และ Drill Files (.drl)
2. อัปโหลด zip ที่ jlcpcb.com (หรือ pcbway.com)
3. ตั้งค่า: 2 ชั้น, หนา 1.6 มม., ทองแดง 1 oz, สีอะไรก็ได้
4. ก่อนสั่ง: เปิด PCB ใน KiCad กด **Inspect → Design Rules Checker** ให้ไม่มี error
3. **รูมอเตอร์** ขนาด 7.0 มม. (มอเตอร์ 716) — ถ้าใช้มอเตอร์ 820 แก้ `MOTOR_HOLE_D = 8.5` ใน `scripts/gen_pcb.py` แล้วสร้างใหม่

## ลำดับการบัดกรี (สำคัญ!)

> แนะนำ: หัวแร้งปลายแหลม + ฟลักซ์ + **hot air** (หรือ hot plate) + ตะกั่วครีม

1. **MPU-6050 (U3) ก่อน** — เป็น QFN ไม่มีขาโผล่ หัวแร้งธรรมดาบัดกรียาก
   ทาตะกั่วครีมบางๆ วางชิป แล้วเป่า hot air ~330°C (สังเกตจุดวงกลมที่ชิป = ขา 1 ให้ตรงกับเครื่องหมายบนบอร์ด)
   ถ้าไม่มี hot air: สั่ง JLCPCB ประกอบเฉพาะชิ้นนี้ได้
2. **USB-C (J2)** — ขาถี่ ใช้ฟลักซ์เยอะๆ ลากหัวแร้ง แล้วใช้ลวดซับตะกั่วดูดส่วนเกิน
3. ชิ้นเล็ก 0805 / SOT-23 / SOD-123 ทั้งหมด
4. **ตรวจไฟก่อนใส่ ESP32**: เสียบ USB แล้ววัดแรงดันที่ C5 ต้องได้ 3.3V
5. ESP32 module (U1) — บัดกรีขาข้างทีละขา, แผ่นใต้ (GND) บัดกรีจากด้านหลังผ่านรูเล็กๆ ได้
6. JST, ปุ่ม, ขา DEBUG
7. มอเตอร์: เสียบมอเตอร์ลงรู 7 มม. (ติดกาวร้อนหรืออีพ็อกซี่) แล้วบัดกรีสาย
   **สายแดง → pad ที่ต่อ VBAT (pad สี่เหลี่ยม/ขา 1), สายดำ/น้ำเงิน → อีก pad**
   มอเตอร์ CW (M1, M4) และ CCW (M2, M3) ต้องวางให้ถูกตำแหน่งและใส่ใบพัดให้ถูกทิศ

## ทดสอบก่อนบิน

1. **ก่อนเสียบแบต**: วัดความต้านทานระหว่าง VBAT กับ GND (ที่ C1) ต้องไม่ช็อต (ไม่ใช่ 0Ω)
2. ตรวจขั้วแบต: สายแดงของแบตต้องไปขา 1 ของ J1 (VBAT) — ขั้ว PH2.0 ของแต่ละยี่ห้อบางทีกลับขั้ว **บอร์ดนี้ไม่มีวงจรกันต่อกลับขั้ว**
3. เสียบ USB → คอมเห็นพอร์ต (ถ้าไม่เห็น: กด BOOT ค้าง แล้วกด RESET แล้วปล่อย BOOT)
4. อัปโหลดโปรแกรมทดสอบ: กะพริบ LED, อ่าน MPU-6050 (I2C 0x68), หมุนมอเตอร์ทีละตัวช้าๆ **ถอดใบพัดก่อน!**

## เฟิร์มแวร์

แนะนำ **ESP-Drone** ของ Espressif (github.com/espressif/esp-drone) — รองรับ ESP32-S3 + MPU-6050 + มอเตอร์ brushed และมีแอปมือถือควบคุม
ต้องแก้ค่าขา GPIO ในโค้ดให้ตรงกับตารางขาด้านบน (มอเตอร์, I2C, LED) แล้วค่อยจูน PID

## ข้อควรรู้

- บอร์ดนี้ **ยังไม่เคยผลิตและบินจริง** — ตรวจสอบก่อนสั่งผลิตจำนวนมาก (สั่งรอบแรก 5 แผ่นก่อน)
- LiPo อันตรายถ้าช็อตหรือชาร์จผิดวิธี ใช้ที่ชาร์จ LiPo 1S โดยเฉพาะ (บอร์ดนี้ไม่ชาร์จแบต)
- ถ้าบอร์ดรีเซ็ตเองตอนเร่งมอเตอร์ = แบตอ่อน/แรงดันตก ให้ใช้แบตที่ C-rate สูงขึ้น

## แก้ไขดีไซน์

- แก้วงจร: แก้ `scripts/design.py` → รัน `./build.sh` → `scripts/route.sh` (เดินลายใหม่ ใช้เวลาประมาณ 5–20 นาที)
- จุดที่ขาชิปถี่มาก (USB-C D+/D- และขาล่างของ MPU-6050) เดินลายด้วยมือไว้ใน `PREROUTE` ใน `scripts/router.py`
  ถ้าย้าย U3, C12, C13 หรือ J2 ต้องตรวจส่วนนั้นด้วย
- หรือแก้ด้วยมือใน KiCad ได้ตามปกติ (แต่ถ้ารันสคริปต์ใหม่ งานที่แก้มือจะถูกเขียนทับ)
